# SlotBuddy Quick Add for Rainbet

This Chrome extension detects the Rainbet slot currently open, lets you edit its name, and adds it to the existing SlotBuddy Bonus Hunt queue.

## Install
1. Download the repository ZIP from GitHub: https://github.com/jessicaedgar1997/stream-leaderboard
2. Extract the ZIP.
3. Open Chrome and go to `chrome://extensions`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted `chrome-extension/rainbet-slotbuddy` folder.

## Connect
1. Open the extension from Chrome's puzzle-piece menu.
2. Click **CONNECT / REFRESH SLOTBUDDY LOGIN**.
3. On the SlotBuddy Bonus Hunt page, sign in with Kick.
4. Reopen the extension. It should show that SlotBuddy is connected.

## Add a game
1. Open a slot on Rainbet.
2. Click the SlotBuddy Quick Add extension.
3. Check or edit the detected game name and Kick username.
4. Click **ADD TO BONUS HUNT**.

The extension requires an authorized SlotBuddy owner/moderator login. It does not read Rainbet balances or place bets.
